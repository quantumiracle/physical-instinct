说明

  • 以中美公司为主（1X 按美国总部计）。其他国家的产品单独标出国别，包括 Franka、Sharpa、UR、Kinova、Shadow、Allegro 等研究常用硬件，以及 FANUC、KUKA、Yaskawa 等工业臂。中国公司在英文名下附中文名，少数找不到可靠中文名的留空。
  • Figure 01/02/03 都已收录；Dyna Robotics 没有公开具体的机械臂型号，表中收录的是 Robo2u 列出的 DYNA 2.1 和 Taku 平台。
  • 同一产品在不同站点的条目已合并；宇树等厂商的教育版、套装和配件变体只保留主型号。
  • 参数、价格和状态来自各数据库，部分是数据库的估计值，各渠道价格差异很大，以厂商报价为准。价格多为美元标价。
  • “视频”优先链接到数据库页面里嵌入的 YouTube 视频；没有的提供 YouTube 和 B 站搜索链接。少数产品没有找到可用图片，用类别图标代替。
  • “模型 / AI”一栏只填了有公开信息的产品，空白不代表没有。

图片与版权

  • 产品图片来自 humanoid.guide、Robotics Center 商店和各厂商官网的公开页面，版权归原厂商或原网站所有，仅用于识别产品。如需移除某张图片，请在 GitHub Issues 提出。

数据来源

  • humanoid.guide：人形机器人、灵巧手和数据采集设备的规格、图片和视频
  • Robotics Center 商店：机械臂、灵巧手、人形和采集套件的价格与图片（含 i2rt YAM 系列）
  • Robo2u Data：发布时间、状态、AI 平台，以及工业机械臂和移动操作平台
