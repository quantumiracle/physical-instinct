类别说明

VLA / 通用策略
一个模型直接输出多种任务、多种机器人的低层动作，通常以视觉语言模型为骨干（RT-2、OpenVLA、π0、GR00T），也包括不带语言模型、但在大规模多本体数据上预训练的通用策略（RT-1、Octo、HPT、公司的闭源“机器人大脑”）。
单任务 / 架构策略
提出一种策略结构或动作表示、通常按任务从少量示教训练的方法，如 ACT、Diffusion Policy、DP3、3D Diffuser Actor。它们本身不是预训练基础模型，但常被用作 VLA 的动作头。
世界模型 / 视频模型
预测未来画面或隐状态的模型，用于合成数据、评测、规划，或者与动作联合生成（世界动作模型，WAM），如 Cosmos、V-JEPA 2、Genie Envisioner、DreamZero、DYNA-2。以视频生成为核心、同时输出动作的策略也归在这里。
具身推理 / 高层规划
负责理解、空间推理、任务拆解和调用工具的视觉语言模型，不直接输出关节动作，而是给出计划、点位或子任务，再交给底层策略，如 Gemini Robotics-ER、Cosmos-Reason、RoboBrain、Pelican-VL。
运动 / 全身控制
面向人形和足式机器人的行走与全身控制模型，多为在仿真中用强化学习训练的动作跟踪或可提示策略，如 HOVER、SONIC、BFM-Zero、BeyondMimic。Helix 02 的 S0、Gemini Robotics 2 等把全身控制并入 VLA 的仍归入 VLA。

开放程度

  • 开放权重：公开发布了预训练权重（部分为非商用许可或需申请）。开源代码：代码公开，但没有可用的预训练基础模型权重。API：可通过接口调用，权重不公开。仅论文：只有论文或技术报告。闭源：只有博客或新闻稿。

说明

  • 发布时间取首次公开（论文、博客或发布会）的月份；之后才开放权重的，在“要点”里注明。
  • 国家按主导机构总部计；Google DeepMind、Hugging Face、1X 计为美国，微软亚洲研究院与清华合作的 CogACT 计为中国。
  • 参数、数据量和性能数字来自论文或公司公告，很多是公司自报、未经独立验证；未公开的留空（—）。参数前带“~”的为根据骨干估算。
  • “机器人”一栏的标签链接到硬件图谱中对应的设备。
  • Tesla Optimus、Skild、Generalist、Dyna 等公司模型没有论文，细节来自官方博客和媒体报道，可信度较低。
  • 没有找到名为“Ti0”的机器人模型，未收录；类似名称的 τ0-VLA（上海创智学院）已收录。乐聚、开普勒等公司的模型缺少可靠公开资料，暂未收录。
